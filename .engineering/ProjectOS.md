# ProjectOS (v1.0)

Welcome to **ProjectOS**, the Engineering Operating Framework for this repository.

This `.engineering` directory acts as the central nervous system for both human engineers and AI Coding Assistants. It provides strict, modular, and technology-agnostic guidelines to ensure extreme consistency, scalability, and security across the codebase.

## System Architecture

1. **[The Runtime Engines](./runtime/)**: The cognitive algorithms governing AI behavior (Context Loader, Review Engine, Workflow Engine, Execution Pipeline, Intelligence modules like Repository Scanner and Impact Analyzer).
2. **[The Boot Layer](./boot/)**: The BIOS sequence that guarantees an AI agent is in a deterministic state before operating.
3. **[The Configuration Layer](./config/)**: Immutable YAML files mapping the specific identity, tech stack, and constraints of this project.
4. **[Workflows](./workflows/)**: Tech-agnostic Standard Operating Procedures (SOPs) for all engineering tasks (e.g., Bug Fixes, New Features).
5. **[Global Standards](./standards/)**: Reusable engineering policies (e.g., Backend, API, Security).
6. **[Composable Reviews](./reviews/)**: Verification checklists adapted dynamically based on project maturity.
7. **[Technology Registry](./registry/)**: The extensible package manager containing knowledge packs for specific technologies.
8. **[Project Memory](./memory/)**: The long-term persistent context of the project (ADRs, tech debt, completed features).
