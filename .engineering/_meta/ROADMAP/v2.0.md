# ProjectOS v2.0 Roadmap

## Theme: The Platform Evolution

While v1.0 focused on establishing the immutable cognitive OS architecture within a repository folder, v2.0 focuses on transforming ProjectOS into a standalone CLI-driven platform.

## Key Deliverables

1. **ProjectOS CLI (`projectos`)**
   - `projectos init`: Scaffolds the `.engineering/` directory in a new repo.
   - `projectos validate`: Runs a linter over custom `.md` rulebooks to ensure they adhere to the Engine Contract.
   - `projectos doctor`: Checks the local repository for configuration drift.
   - `projectos review`: Manually triggers the AI Review Engine locally.
   - `projectos plugin install`: Installs third-party tech stacks.

2. **Distributed Memory Engine (Semantic RAG)**
   - Transitioning `.engineering/memory/` from static keyword matching to a local Vector DB to eliminate context truncation.

3. **Multi-Agent Collaboration**
   - Upgrading the Runtime Pipeline to allow the Backend Persona and QA Persona to execute and converse simultaneously.
