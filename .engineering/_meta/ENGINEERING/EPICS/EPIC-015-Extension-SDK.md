# EPIC-015: Extension SDK

## Goal
Design the Extension SDK to allow external developers to extend ProjectOS without modifying the core.

## Scope
Extension points for: Technologies, Frameworks, Templates, Reviews, Workflows, Policies, Validators, Context Providers, Output Formatters.

## Acceptance Criteria
- [ ] Defines Plugin lifecycle, Registration, and Dependency management.
- [ ] Defines Compatibility rules, Security model, Sandboxing strategy, and Version negotiation.
