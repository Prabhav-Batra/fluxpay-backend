# EPIC-005: Runtime Engine

## Goal
Implement the core cognitive pipeline. Using the frozen `ARCHITECTURE.md`, generate complete production specifications for all runtime engines.

## Deliverables
- `Intent Engine`
- `Task Classification Engine`
- `Context Resolution Engine`
- `Technology Resolution Engine`
- `Policy Engine`
- `Planning Engine`
- `Workflow Resolution Engine`
- `Persona Resolution Engine`
- `Execution Engine`
- `Verification Engine`
- `Review Engine`
- `Output Engine`

## Acceptance Criteria
- [ ] Each engine specification strictly implements the Universal Engine Contract (Inputs, Outputs, Failure Modes, etc.).
- [ ] Cross-references shared interfaces rather than duplicating information.
