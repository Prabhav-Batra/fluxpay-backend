# EPIC-014: ProjectOS CLI Specification

## Goal
Design the ProjectOS CLI as a language-agnostic platform tool.

## Scope
Commands must include: `init`, `doctor`, `validate`, `scan`, `review`, `explain`, `upgrade`, `plugin install`, `plugin list`, `workflow run`, `context`, `generate`.

## Acceptance Criteria
- [ ] For every command, defines: Purpose, Inputs, Outputs, Exit Codes, Validation, Dependencies, Examples, and Error Handling.
